# Портфолио Дианы Фатыковой

Готовый статический сайт-портфолио. Не требует сборки, npm или сервера приложений.

## Локальный просмотр
Откройте `index.html` в браузере. Для корректной работы всех браузеров рекомендуется запуск через локальный статический сервер.

## Публикация по интернет-ссылке (бесплатно)
Самый простой способ — Netlify Drop:
1. Откройте https://app.netlify.com/drop
2. Войдите или зарегистрируйтесь.
3. Распакуйте архив и перетащите папку `diana-portfolio-site` целиком в область загрузки.
4. Netlify опубликует сайт и выдаст публичную ссылку вида `https://....netlify.app`.
5. При желании в настройках сайта можно изменить имя поддомена.

Альтернатива: загрузить папку в Cloudflare Pages или GitHub Pages как статический сайт.

## Структура
- `index.html` — сайт, навигация и галереи
- `assets/images/` — все оригинальные изображения, оптимизированные в WebP
- `assets/projects/` — 21 изображение страниц PDF-презентаций
- `assets/pdfs/` — исходные PDF-файлы

В проекте 3 PDF-проекта (8, 12 и 1 слайд), 12 иллюстраций, 7 ИИ-обложек и 4 дополнительные графические работы.
